## 2. STEP → W 变换（G5）
```
W_T_STEP = [[1,0,0,4500],
            [0,1,0, y_world],
            [0,0,1, 0],
            [0,0,0, 1]]
```
- 平移：**(4500, y_world, 0)**，y_world ∈ {350, 816.7, 1283.3, 2216.7, 2683.3, 3150}
- 旋转：**单位阵**（`translate()` 只含平移，无旋转烘焙）
- 证据：两个实例化 STEP 的球心分别精确落在 (4500, **1283.3**, 0) 与 (4500, **350.0**, 0)，与 `Y_WORK` 表逐位吻合
- 判定：**POSITION_RECOVERED + ORIENTATION_VERIFIED**（旋转为单位阵，非推测）
