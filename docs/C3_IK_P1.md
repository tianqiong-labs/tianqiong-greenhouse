## 1. 位置可达：成立
三个位置都有 9–16 组有效解，关节余量 80–140°，L4 余量充足（≥100 mm）。

## 2. 但残差 1.9–3.0 mm，对对接偏大
γ-2 的球心与腕柱需要 <1 mm 量级才能建立配合。当前是**搜索精度**问题（步长 50/3°），不是无解——继续细化可收敛。

## 3. 关键问题：末段角 a4 ≈ −24…−27°
γ-2 的跑道槽开口朝 +X 是**建立在末段水平**（a4=0）的前提下。a4=−25° 意味着接口轴线相对设计方向倾斜约 25°，于是：
- 开口不再是 +X，而是斜向下约 25°
- 撤离方向与设计不符
- 腕柱与 C 形槽的相对姿态随之偏转

**按 P2 规则：位置可达但对接姿态不满足的解，不列入有效候选。**
本轮搜索的所有最佳解都在 −24…−27°，因此**没有一个直接满足 γ-2 对接姿态**。

## 4. 两条出路
| 方案 | 做法 | 影响 |
|---|---|---|
| A | 追加"a4≈0"的约束搜索，看是否存在末段水平的解 | 若存在，接口方向不变，代价最小 |
| B | 让接口适应 a4≈−25°，即球头/卡箍整体绕 Y 倾斜 25° 安装 | 改 γ-2 安装基准，接口与臂末端不再是原装配关系 |

## 5. 判定
C3 的**位置可达**已确认；**对接姿态**尚未满足。C3 仍为 CONDITIONAL。
