# C3 布局与 IK 复核（修正三处）

## 1. 坐标：球心 ≠ 锚轨中心（偏距 120 mm）
| 项 | 原布置 | 整体 -200 后 |
|---|---|---|
| 球心 | 4500 | 4300 |
| 轨中心 | 4620 | 4420 |
| 腹板 | 4560…4680 | 4360…**4480** |
| 压条 | 4473…4497 | 4273…4297 |

**两个硬结论：**
1. 腹板外缘 4480 距膜边 4485 只剩 **5 mm** —— 内置后锚轨几乎顶到膜边。
2. 压条若跟着平移会落到 4273…4297，与膜边 4485 完全错位。**压条必须留在 4485，由独立结构承托**（这就是门架存在的真正理由，不是"可选加强"）。

## 2. 真实 IK（不是共线估算）
| 目标 | 残差 | 关节角 | L4 | 实际末端 |
|---|---|---|---|---|
| (4300, 0) | 0.9 mm | [−12, −12, −62, −40] | **1450** | (4299.1, −0.1) |
| (4420, 0) | 0.1 mm | [−12, −56, −42, −16] | 1450 | (4420.0, 0.1) |

修正：共线估算给的是 L4=1081，真实 IK 是 **L4=1450**（在 1000…1600 内，但余量是 150，不是 81）。
**共线法只能筛"够不够得着"，不能当 IK 结论。**

## 3. 门架净空：按完整机构扫掠，不是球头 67
腕柱顶到 **z=194**，卡箍 90…110，导轨 82…88。门架下沿必须按这些件的**运动扫掠包络**定，而不是球头顶 67。

## 4. 门架定位（保护"一臂两用"）
| 方案 | 后果 |
|---|---|
| 门架替代六臂承托 | ❌ 六臂退化为普通作业臂，丢掉核心创新 |
| **门架只做前檐承托 + 膜边固定 + 载荷转接** | ✅ 六臂仍承担可重构棚面支撑 |

需给出两个工况的传力路径：六臂全部署 / A02A05 脱离四臂承托。

## 5. 当前判定（五项关口）
