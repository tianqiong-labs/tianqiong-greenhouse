## 3. 总装包围盒

```
x  -630.0 …  4567.0     （棚内 4.57 m）
y  -186.7 … 12111.3     （三模块，约 12.1 m）
z   -67.0 …  3149.5     （棚高 3.15 m）
```

两处异常，均为**既有几何**，不擅自修正：

1. **z = −67**：球头半球有 67 mm 落在地面以下（球心定在 z=0 的直接后果）。
2. **y = −186.7**：模块 0 的零件越过 y=0 向左延伸 186.7 mm，说明"模块原点"与"母墙左端"并不重合，需要在下轮明确以哪个为准。
