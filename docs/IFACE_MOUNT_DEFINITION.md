# γ-2 安装基准定义（单一定义版，2026-10-26）

本文件替代此前所有版本；旧表述（“M1 已成立”“刚接必须 a4≈0”“120·cos(a4)”）**一律废止**，不再保留于正文。

## 1. 现状
| 项 | 状态 |
|---|---|
| 接口相对末段的安装方式 | **未确定** |
| 固定安装角 β（刚性安装） | 待验证 |
| 可调补偿座 | 备选，未设计 |

设末段绝对角为 a4，接口相对末段安装角为 β，则接口轴线方向 θ_接口 = a4 + β。
β 固定时，只有 a4 = −β 那一个姿态能让接口世界对齐；其他姿态接口随之倾斜。

## 2. 事实核对
| 项 | 值 |
|---|---|
| 部署态 a4 | **−57.18°** |
| 现 CAD 中法兰/卡箍/跑道槽 | 全部世界对齐（水平盘、竖直环、开口沿 +X） |
| 由 1 推得 | 现几何对应 β ≈ **+57.18°** 的固定安装，而非“存在调平座” |

**“静态 CAD 世界对齐”只能推出这个 β，不能推出任何可调机构。**

## 3. 两种候选定义（均未验证）
| | 固定安装角 | 可调补偿座 |
|---|---|---|
| β | 恒定 ≈ +57.18° | 随 a4 变化 |
| 接口姿态 | 仅部署态对齐；其他 a4 倾斜（a4=−24° 时倾斜 **33.18°**） | 全程可对齐 |
| 新增自由度 | 0 | +1 |
| 代价 | 换姿态即改接口朝向 | 需设计座、行程、锁止、承弯矩 |

## 4. 偏距
球心→轨中心 120 mm 是在“接口水平、腕柱竖直”下测得的装配偏距。
是否随 a4 变化，取决于哪些零件旋转、旋转中心与完整安装变换，**不能简化为 120·cos(a4)**。

## 5. 结论
- 当前的正确表述是“**固定安装角待验证；补偿座为备选**”。
- 下一步：建立末段→接口的完整刚性变换（含安装位置、旋转中心），验证 β≈+57.18° 能复现原部署态的球心、腕柱轴线与开口方向。
