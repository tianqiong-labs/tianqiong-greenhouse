## 读法
- 共线 L4 随内移单调下降（1081→1023），**但这只是筛查值**；真实 IK 给出的是 1320…1560。
- 4300 / 4280 的真实解都落在 **L4=1560**，距上限只有 **40 mm** —— 这一族解很靠近伸缩极限。
- 4250 给出 1520（余量 80），4230 出现 1320（余量 280），说明再内移反而有更宽松的解族。

## 注意（不能当成结论）
以上 IK 是**从 4300 解出发的局部搜索**，不是全局最优；不同关节分支会给出不同 L4。因此"某个位置 L4 余量小"不等于该位置不可行，只说明**这一分支**紧。
