# 方案 A 可行性（33 mm 横移 + 抬升撤离）

## 1. 首碰修正（采用 z=22）
`dx_contact = 100 − √(67²−22²) = 36.7 mm`（上一版用 z=30 得 40.1，作废）

| dx | 净空 |
|---|---|
| 0 | +35.4 |
| 25 | +11.2 |
| 30 | +6.4 |
| **33** | **+3.5** |
| 35 | +1.6 |
| 36.7 | 0.0（首碰） |

B-Rep 复核：dx=29/31/33/35/36.7 交集均为 **0.0**；dx=40 为 **148.5 mm³**。

## 2. 33 mm 是否解除接口约束
- 腕柱 r15 在球头局部 x=+33 处，左缘 18 mm；跑道槽起点 14 mm → 让开 4 mm
- **但这只是"槽内无干涉"，不等于离开球头外廓**：球头在 z 14…76 的外半径仍覆盖 x 18…48
- 结论：33 mm 给出的是通道，不是自由度

## 3. 第二段：抬升可达性
在部署姿态邻域搜索 4 个俯仰角 + L4=1600：

| 项 | 值 |
|---|---|
| 解 | q = [−25, −10, −20, −65] |
| 末端 | x = 4506，z = **104** |
| 球最低点 | 37.4（轨顶 30）→ **+7.4 mm** |
| 关节变化 | [−23.4, +10.1, +18.6, −7.8]° |

即在现有自由度内存在一个"抬到球底离轨 7.4 mm"的姿态，抬升约 104 mm。

## 4. 判定（当前层级）
| 条件 | 状态 |
|---|---|
| 正常解锁 | ✅ γ-2 已验证 |
| 33 mm 横移不穿背压轨 | ✅ 0 交集（余量 3.5 mm） |
| 存在抬升姿态 | ✅ 可达（+7.4 mm） |
| 后续**连续**无碰撞路径 | ❌ 未验证（仅端点姿态） |
| 重新对接 | ❌ 未验证 |
| 四臂连续承托 | ❌ 未触及 |

**结论：A 通过第一层筛选（静态几何 + 运动学可达），尚未通过完整路径验收。3.5 mm 与 7.4 mm 两处余量都低于制造/装配误差量级，必须由轨迹级验证确认。**
