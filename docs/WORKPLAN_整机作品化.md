**定位（已冻结）**：概念整机模型作品 — 核心创新为中心、整机表达为重点、逻辑自洽为底线。

## 3. 答辩主线（固定讲法，不再发散）

> 传统暖棚与农业机器人是分离的两套资源。田穹用模块化母墙 + 可变构机械肋骨 + 前沿锚轨 +
> 可收纳围护，让同一套机电资源兼顾结构支撑与农业作业，提高设施复用率、部署灵活性与场景适应性。

五页逻辑：痛点 → 构型 → **一臂两用（核心创新）** → 模式切换（补位→释放→作业→复位） → 转场收纳与绿色经济。

**六臂理由（P1 必须补的叙事）**：4 臂时释放 2 臂只剩 2 臂承托，覆盖面无法维持；6 臂释放 2 臂后仍有
**4 臂承托**，并通过双轨 Y 补位把剩余四臂重新分布（350 / 816.7 / 1283.3 / 2216.7 / 2683.3 / 3150），
才使「膜保持展开条件下作业」这一不变量成立。这是 6 臂的功能必然性，不是冗余。
