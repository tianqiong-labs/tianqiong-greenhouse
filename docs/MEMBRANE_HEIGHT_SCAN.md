# 膜边高度扫描（方案 3）结论：C —— 不存在连续膜面路径

## 1. 各高度上"膜边要避开的最小 x"
| z | 最小件左缘 | 膜边须 x ≤ | 阻挡件 |
|---|---|---|---|
| 24 | 4437.4 | 4433.4 | 球头 |
| 60 | 4470.2 | 4466.2 | 球头 |
| 70 | 4476.0 | 4472.0 | 凸台 |
| 80 | 4480.0 | 4476.0 | 法兰 |
| 90 | 4478.0 | 4474.0 | 支架 |
| 100 | 4484.0 | 4480.0 | 卡箍环 |
| 110 | 4484.0 | 4480.0 | 卡箍环 |
| 130 | 4485.0 | 4481.0 | 腕柱 |
| 150 | 4485.0 | 4481.0 | 腕柱 |
| 200 | — | — | 无阻挡 |

**抬高膜边并不能"一次避开"**：z=70 撞凸台、z=80 撞法兰、z=90 撞支架、z=100–110 撞卡箍、z=130–150 撞腕柱。只有 z≥200 完全无阻挡，但那是棚顶高度，不是檐口。

## 2. 撤离约束更硬
120 mm 撤离后球头最左 = 4380 − 67 = **4313** → 膜边必须 ≤ 4309。
即膜边低位的可达位置被压在 4295…4309（这就是 B 的 190 mm 开放带来源）。

## 3. 拓扑判断（决定性）
锚轨在 x=4500，位于棚膜**之外**。机械臂要从棚内伸到锚轨，必须在 z 0…67 的通道内穿过任何位于其路径上的膜面位置。
因此：

- 膜边放低（z≈24）→ 球头穿膜；
- 膜边抬高（z 70…150）→ 撞凸台/法兰/支架/卡箍/腕柱；
- 膜边再抬高（≥200）→ 已到棚顶，檐口无法封闭，且球头仍在 z 0…67 自由进出（开口依旧存在）。

**结论：C —— 在现有机械臂与锚轨布置下，六个臂位不存在连续膜面路径。**
高度不是变量；根因是"机械臂必须穿出围护去对接锚轨"。

## 4. 三个可选出路（下一轮选一）
| 编号 | 做法 | 代价 |
|---|---|---|
| C1 | 局部可变形围护（S′ 双层或单向阀式帘片） | 需验证回位与不阻运动 |
| C2 | 六处永久开口 + 独立防水帽/袖口（O） | 破坏"连续膜"叙事，六处防水 |
| C3 | 改接口布置：把锚轨移到膜内侧，机械臂不再穿膜 | 动的是锚轨与整机布局，影响最大但最彻底 |
