## 4. 开槽后的初始态

在六个臂位的槽范围内压条材料被移除，因此：

- 球头 ↔ 压条：−53.17 → 不再接触
- 腕柱 ↔ 压条：−9.5 → 不再接触
- 球头 ↔ 腕柱：−67（重叠）→ **+1.0 mm 间隙**（设计配合）

即初始支撑态不再含非法穿透——前提是槽按上表落到位。
