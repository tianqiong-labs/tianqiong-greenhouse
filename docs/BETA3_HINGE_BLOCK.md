# β-3 摆舌：绕 X 轴旋转为什么不可能通过（解析）

## 几何事实
球心 (0,0,0)，上半球 r=67；凸台 r=24，z 58…76；孔 r=16，z 14…76。
摆舌封口位于 x 16…28、y ±15、z 14…76。

## 关键约束
绕 **X 轴**旋转只改变 (y,z)，不改变 x。因此摆舌任一点到 Z 轴（腕柱轴）的距离
ρ = sqrt(x² + y²)，当 y 被转到 20～30 时，ρ ≈ 25～40。

而该高度处球面半径：
- z=40 → 53.7
- z=50 → 44.6
- z=60 → 29.8

只要 ρ < sqrt(67²−z²)，点就在球体内部。摆舌在 z 14…60 区间旋转时，
ρ 始终小于球面半径（除非 y 被转到 60 以上，而那时已撞球头外侧）。

**结论**：绕 X 轴旋转无法把摆舌移出球体——不是铰点位置问题，是旋转轴问题。
唯一例外是旋转到 z>67 以上，但那里正是凸台（z 58…76）。

## 可行替代
绕 **Z 轴（竖直轴）** 旋转：摆舌在 +X 通道内（x 14…104，y ±16，z 14…76）
转动 90°，贴到通道侧壁。通道本身是贯通的，因此不碰球体，也不削主承载壁。
