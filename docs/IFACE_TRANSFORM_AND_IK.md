# 固定安装变换与姿态约束 IK（2026-10-26）

## 1. 坐标系与变换
- W 世界：+X 棚内、+Y 沿墙、+Z 上
- E 末段系：原点在球心，x 轴沿末段
- I 接口系：原点同球心，+X 为开口方向，+Z 为腕柱轴向

固定安装：`W_T_I(q) = Trans(tip(q)) · Rot_Y(β)`，`β = −a4₀ = +57.2°`
（安装位置与旋转轴一并定义，不是单纯"转 57.18°"）

## 2. 部署态复现
| 项 | 值 |
|---|---|
| tip | (4500.146, 0.436) |
| 目标 | (4500, 0) |
| 误差 | **0.45996 mm** |

0.46 mm 与已知 `anim/planner` 系统性偏差（dx −0.150 / dz −0.440）一致，属于该已知缺陷，不是变换错误。

## 3. 扰动检查（刚性随动）
| a4 | 接口倾角 |
|---|---|
| −70.0° | 12.80° |
| −57.2° | **0.00°** |
| −45.0° | 12.20° |
| −24.0° | **33.20°** |

倾角严格等于 `|a4 − a4₀|`，安装变换保持不变 → 固定安装是刚性随动，不会"自动调平"。

## 4. 姿态约束 IK（a4 限定 −57.2°±2°，位置容差 0.5 mm）
| 候选 | 结果 |
|---|---|
| 4250 | 本轮覆盖范围内**未找到** |
| 4280 | 本轮覆盖范围内**未找到** |
| **4230** | **找到 1 解**：残差 0.045 mm，a4=−57.7°，L4=1400，倾角 0.5°，相对关节限位合格 |

网格步长 2.5°／L4 步长 100 mm，因此"未找到"只代表本轮覆盖范围内未找到。

## 5. 判定
在固定安装（无补偿座）前提下，**4250/4280 目前无满足姿态的解，4230 有一个**。
这意味着若要保住接口世界对齐，末端需继续内移；是否接受 4230 的棚内占用需另行评估。
