## 3. 仍存在的实现缺陷（未解决）
当前脚本只计算 **末端位置 + 标量倾角 |a4−a4₀|**，**没有生成旋转矩阵与齐次变换**，`rot_identity` 也是同角度比较得到的布尔值。文档中的 `W_T_I = Trans(tip)·Rot_Y(β)` 漏掉了末段随 q 的旋转，β≠0 时不能得到单位旋转。

正确形式应为 `W_T_I(q) = W_T_E(q) · E_T_I`，其中 E_T_I 由部署安装基准固定得到；球心、开口方向、轴线都要用矩阵变换，而不是角度公式。**此项待实现。**
