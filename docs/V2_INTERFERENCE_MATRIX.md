## 3. 横向挡止回归（跑道槽后）

| 检查 | 结果 |
|---|---|
| 柱 +X20 vs 球头 | 0（跑道槽已开口，球头不再挡） |
| 柱 +X20 vs C 形法兰 | 0（法兰开口 32 mm，也不挡） |
| **柱 +X20 vs 卡箍环（闭合 s=0）** | **9,832.8 mm³ → 挡止成立** |
| 柱 +X20 vs 卡箍环（张开 s=20） | 0 → 可通过 |

**结论：横向锁止已完全由卡箍环承担，球头与法兰都不再提供挡止。** 这与之前"球头 C 槽挡止"的说法不符，必须更新设计叙述：球头只管导向与承托，X 向锁止＝卡箍环。
