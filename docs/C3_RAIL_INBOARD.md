# C3：P03 锚轨内置可行性（几何与运动学初筛）

## 1. 可达性（末端 z=0）
机械臂：三段 4050 + 第四段 1000…1600 → 总长 5050…5650 mm，根部 (0, 2800)。

| 锚轨 x | 距根距离 | 需要 L4 | 判定 |
|---|---|---|---|
| 4500（现状） | 5300 | 1250 | 可达 |
| 4430 | 5241 | 1191 | 可达 |
| 4400 | 5215 | 1165 | 可达 |
| 4350 | 5173 | 1123 | 可达 |
| **4300** | **5131** | **1081** | **可达** |
| 4200 | 5048 | 998 | 低于 L4 下限（需折臂配合） |

结论：锚轨内移到 4300 仍在伸缩范围内，且 L4 余量充足（1081 vs 1000）。

## 2. 是否真的不再穿膜
- 膜边（旧）x=4485，膜面在 z≈24 落至檐口
- 锚轨内置 4300 后，末端最远只到 4300 → 与膜边差 **185 mm**
- **机械臂不再到达膜边所在 x，因此不穿膜**（这是 C3 的核心收益）

## 3. 但产生一项新的结构义务
檐口压条在 4485，比锚轨外 185 mm。锚轨内置后**无法直接托住压条**，必须由**跨越机械臂上方的门架**支撑：
- 门架下沿需高于球头最高点（z ≥ 67 + 余量）
- 门架外侧立柱落在 4485 附近，位于膜内还是膜外需另定
- 这是新增的承载件，不是已有零件搬家

## 4. 空间代价
| 项 | 影响 |
|---|---|
| 棚内占用 | 锚轨从 4620 内移到 4300，占 **320 mm** 宽条带 |
| 种植/作业空间 | 前沿 320 mm 变为结构带 |
| 地锚 | 现有地锚按 4620 线布置，需整体内移 |
| 六臂姿态 | 末端 x 由 4500 改 4300，六段轨迹全部要重算 |
| 膜面 | 膜边可保持 4485 不变（收益），但支撑方式改为门架 |

## 5. 判定：**CONDITIONAL**
| 项 | 状态 |
|---|---|
| 六臂可达 | ✅（4300 处 L4 余量 81 mm） |
| 不穿膜 | ✅（末端最远 4300 < 膜边 4485） |
| 四臂承托可保持 | ✅（结构不变，仅位置） |
| 需要新增门架 | ⚠️ 必须，且未设计 |
| 地锚/基础重排 | ⚠️ 必须 |
| 六段轨迹 | ⚠️ 全部重算（未做） |

**C3 几何成立，但不是"平移锚轨"就能完成**：必须新增跨越门架、内移地锚、重算六臂轨迹。

## 6. 与 C1/C2 的比较
| | 改动量 | 是否保留"连续膜" | 风险 |
|---|---|---|---|
| C1 可变形围护 | 小（局部帘片） | 是 | 回位/夹持未证 |
| C2 六处开口 | 中 | 否 | 六处防水 |
| **C3 锚轨内置** | **大（锚轨+地锚+门架+轨迹）** | **是** | 结构件新增、空间占用 |
