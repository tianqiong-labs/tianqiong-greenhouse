# 坐标基准核验（Assembly V1 之后，2026-10-25）

基线 `fae292b` 的 `assembly_v1.step` 不重导、不改动。本文件只关闭坐标口径。

## 1. y = −186.7 的来源（结论：分析脚本错误，非模型偏移）

证据链：

| 项 | 值 |
|---|---|
| 记录 | `M1_M1_W01_C03_carrier_body` 等 |
| 记录里的 `c` | **−186.7** |
| 网格顶点（烘焙坐标） | y 1295.0 … 1645.0（中心 1470 = A03 名义位） |
| 顶点 + c | y 1108.3 … 1458.3（中心 **1283.3** = A03 补位位） |

`mesh` 类记录的 `c` 是**增量**，几何顶点里已烘焙名义坐标。上一版包围盒统计把 `c` 当绝对坐标，于是把 A03 的补位量 −186.7 错当成整机原点偏移。

**因此：不存在 186.7 mm 的原点偏移，也不能把 A03 的补位量用于全局修正。**

## 5. 0.465 mm 偏差归因（已定位性质）

18 个末端全部同一残差：

| 分量 | 值 | 标准差 |
|---|---|---|
| dx | **−0.150 mm** | 0.0000 |
| dz | **−0.440 mm** | 0.0000 |
| \|d\| | 0.465 mm | — |

标准差为 0 → **不是逐臂几何差异、不是导出误差**，而是两套链式求值对"末端参考点"的定义差异（工具参考点偏移）。归入**定义统一问题**，不属于装配误差。要彻底消除需要统一 `anim` 与 `planner` 的末端定义，属下一轮工作。

## 6. 烘焙坐标纪律（写入规范）

1. `mesh` 记录的 `c` 是**增量**，不得当绝对坐标；
2. 求包围盒/干涉必须用顶点级数据；
3. 同一偏移不得重复叠加（记录 `c` 已含模块偏置与补位量）。

## 7. 结论

| 问题 | 结论 |
|---|---|
| y=−186.7 原点偏移 | **不存在**，是统计脚本把 mesh 的 `c` 当绝对坐标 |
| 是否需要修正模型 | **不需要**，几何本身正确 |
| 需要修正的 | 分析脚本的包围盒函数（已在本轮重算） |
| A03/A04 的 ±186.7 | 是补位量，只属于运动状态，不得进入世界基准 |
