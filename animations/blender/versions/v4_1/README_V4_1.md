# V4.1 三模块上部结构

按用户确认的架构修正：一母墙一模块，三个母墙对应三个模块；各自配置六臂、顶部固定卷筒、独立顶膜及前缘牵引杆。三模块之间采用固定柔性顶部桥接膜，每侧搭接 120 mm。

工程：`output_v4_1/TIANQIONG_V4_1_upper_modules.blend`。原 V4 工程保留在 `output/`。

## 使用

- 默认第 361 帧：三模块顶膜全部展开。
- 第 1–121 帧：M1 展开；第 121–241 帧：M2 展开；第 241–361 帧：M3 展开。
- 三个模块分别放在 M1/M2/M3 集合；模块连接单独归组。
- 每模块的 `DEPLOY_CONTROL` 空物体有 `deploy` 属性（0 收卷、1 展开）；顶膜、牵引杆和卷筒由同一属性驱动。手动调节时需先禁用对应属性动画。

## 本次修正

移除 V4 的两端山墙膜、端墙立柱及胶条、下部裙边、整棚连续后衬板。顶部后泛水改为按模块独立构件；连接带单独处理。增加纵向承托杆和机械臂可脱开承托座的几何位置，预留后续四臂支撑、两臂作业的设计空间。本轮骨架固定在展开状态，接口尚未建立释放运动与承载验算。

膜沿骨架外偏 110 mm 的圆滑承托面铺设，顶部收卷、向前下方放膜。牵引杆沿曲面法向外偏 28 mm，端部内缩以避让边缘密封。前沿路径从旧锚轨上方通过，模型止于顶部前沿接口；下部和两端故意开放，不视为整棚气密验收。

## 检查与边界

`geometry_report.json` 为膜路径与牵引杆对原 CAD 五金的 8811 点采样检查；`assembly_animation_check.json` 为重新打开已保存工程后对 361 帧和独立 M2 控制的验证。新结构之间的完整连续碰撞、膜受力、密封压紧公差、作业臂释放后的受力与收纳运动留待后续，不能由当前采样净空代替。
