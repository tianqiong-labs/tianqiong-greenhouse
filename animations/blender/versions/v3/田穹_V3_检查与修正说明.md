# 田穹 F04 R02：V1/V2 核查与 V3 修正

## 查明的错误

1. **重复转换坐标。** 原 GLB 为 glTF Y-up，Blender 导入器已经恢复为 CAD 对应的米制 Z-up。V1 的动画与地面按 Y-up 搭建，V2 又手动绕 X 转了 90°，都没有正确使用导入后的世界坐标。
2. **锚轨方向错误。** 正确 P03 主轨包络为 X=4.56–4.68 m、Y=0–3.5 m、Z=0.032–0.066 m。V2 把它转成了竖直构件，因此棚体看起来像竖排栏杆。
3. **转轴与源模型不一致。** `01_deployed.glb` 的根座 Y 坐标是 0.350、0.910、1.470、2.030、2.590、3.150 m；之前脚本用了补位后的另一套坐标，转轴没有对准关节。
4. **伸缩绑定错误。** 原第四关节位于第三杆末端，不能跟随伸缩内管回缩。之前连第四关节一起移动，并用平移替代内管露出长度变化，导致分离和错位。
5. **膜的展开方式有误。** 之前只压缩 X，没有同步处理高度，把收起状态的膜变成了竖直帘状物。V3 同时处理 X/Z，保持原 CAD 膜面及加强件的拓扑，完整展开时恢复源 CAD 位置。

## V3 如何重建

- 直接使用 Blender 导入后的世界坐标，保留 X 向棚内、Y 沿棚长、Z 向上及米制单位。
- 先冻结并校验源 CAD 各网格的世界坐标，再复制三套模块，模块节距沿 Y 为 4.25 m。
- 从原装配 JSON 读取每根臂的实际关节点，按刚体变换计算三根固定杆和第四段外管；内管使用沿自身轴线的长度变化，第四关节固定在第三杆末端。
- 中间模块 A02/A05 采用 F04 R02 的局部释放候选：门打开、头下降 80 mm、末段 1600→1000 mm、整体根俯仰下降 6°，之后反向复位。橙色用于标明这两根臂。
- 完整部署/复位姿态与源 CAD 逐顶点核对；全片逐帧核对杆件连接和内管末端。

## 概念动画的范围

机械臂折叠与模块移动是展示关键帧，没有通过完整碰撞/运输验证。膜采用原 CAD 网格的概念展开变形，不是柔性膜或等料长卷绕仿真。模块间 750 mm 区域沿用源资产的间隔，本版未虚构小墙和跨模块密封。
