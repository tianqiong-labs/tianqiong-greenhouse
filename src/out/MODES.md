# 田穹两套运动模式（状态机）

两个模式共享同一装配图与关节模型，但**入口状态与约束不同**，不能混成一条时间轴。

## 模式 A｜正常农业作业（棚膜保持展开）

```
[A0] 部署支撑态（膜展开，六臂承托，滑块锁定）
  └─ 双轨同步补位 + 支撑确认（其余四臂接管荷载）
       └─ 2/5 号：承托头解锁 → 闸门开 → 承托头下降
            └─ 末端与前沿海块快脱（滑块留在锚轨内）
                 └─ 第四段回缩
                      └─ 【待补】根部附近折成紧凑 Z 形，抬离相邻臂包络
                           └─ 根部回转 35° + 俯仰协调进入作业区
                                └─ 作业 → 反序返回 → 重新对接 → 恢复承托
```
不变量：膜始终展开；任何时刻至少四臂处于承托状态。

## 模式 B｜整棚收纳迁移（各臂已回到支撑位）

```
[B0] 部署支撑态（与 A0 相同，但六臂全部回到初始位）
  └─ 解除膜面接口 → 母墙侧收膜（602 → 7200 mm，卷径 Ø122.5 → Ø147.4）
       └─ 地锚回缩 620 mm
            └─ 机械臂协同搬轨（IK 546 位姿，最小间隙 27.4 mm）
                 └─ 六臂 Z 字形折叠（75°，臂间 462 mm）
                      └─ 轮组伸出 160 mm，墙体抬离地面
                           └─ 小墙/端墙/过渡轨拆卸收纳 → 模块独立运输
```

## 切换规则

- A → B：必须所有臂回到支撑位、承托恢复、膜面无解除；否则不允许进入收膜。
- B → A：按逆序恢复，锚轨锁定、地锚伸出、膜展开张紧后，才允许承托锁定。
- 非法转换（例如膜已收却要求“保持覆盖下作业”）由状态机拒绝，不允许在动画层绕过。
